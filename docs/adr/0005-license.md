# 라이선스는 MIT로 둔다

지금 LICENSE 파일이 없다. public 레포는 라이선스가 없으면 남이 쓰기 어렵다.

Que는 개인 도구이고, 강한 copyleft가 필요한 네트워크 서비스가 아니다. MIT가 이 규모에서 기본이다. Apache-2.0은 특허 문구가 있으나 이 레포의 핵심은 파서와 UI라 이득이 작다. GPL은 self-host 허들을 키운다.

공개 브랜치에는 외부 모델 기반 번역 기능을 포함하지 않는다.

- **Status**: accepted
- **Considered Options**: MIT, Apache-2.0, GPL-3.0
